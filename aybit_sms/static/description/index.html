Aybit SMS Provider

SMSOrigin integration for Odoo

This module provides an SMSOrigin provider for Odoo's IAP (In-App Purchase) system. It allows you to send SMS messages through SMSOrigin API instead of Odoo's default IAP service.

Configuration

  • Go to Settings > IAP Accounts
  • Create a new account with Provider "SMSOrigin (Aybit)"
  • Enter your SMSOrigin credentials (username, password, channel code)
  • Optionally set a custom originator (sender name)
  • Click Check Credit to verify your credentials
  • Set as default SMS account

Features

  • Turkish character support (ISO-8859-9 encoding)
  • Automatic phone number normalization (90XXXXXXXXX format)
  • Batch SMS sending
  • Credit balance checking
